# Fake News Classification

A minimal Streamlit demo using TF-IDF and Logistic Regression (or the best model selected in the notebook).

**Before deploying:** add `models/fake_news_model.pkl` and `models/tfidf_vectorizer.pkl` from your trained notebook to this Space. No original CSV dataset is needed.

This is a demonstration of statistical text classification, not independent factual verification.
